# ADR 007: トレンドスコア（チャート背景）

## ステータス

Accepted（v0.2.0 / Phase 4）

## コンテキスト

v0.2.0 Phase 3 で分類付きのテクニカル指標カタログを載せた。同一指標が複数分類に出る（MACD はトレンドとモメンタム、RSI はモメンタムとオシレーターなど）ため、分類ごとの点数を足すと二重計上になる。
チャート上で「今どの方向か」を一目で示す手段もなく、指標トグルの ON/OFF に判定を依存させると相場認識が揺れる。

## 決定

**日足ごとに指標を 1 グループへ固定して -100〜+100 で採点し、グループ配点で総合スコアを合成してチャート背景色にする。結果は DB に保存しない。**

- カタログ UI の複数分類表示は [ADR 006](006-indicator-catalog.md) のまま残す
- スコア用グループは `scoreGroup`（1 指標 1 グループ。エリオットは `null`）
- 計算は FastAPI `POST /trend-score`。公開面は Nest `GET /symbols/:id/trend-score`（JWT）
- 指標リストはサーバ側の正本セット。チャートのトグルとは独立
- lookback・週足集約・`INSUFFICIENT_PRICE_DATA` / `ANALYSIS_UPSTREAM_ERROR` は指標 API と同じ
- 表示期間より前は Nest が trim する。一目の未来点はスコアに含めない

### グループ配点

- トレンド系 ±40（方向性）
- モメンタム系 ±20（勢い）
- オシレーター系 ±10（過熱・売られすぎの補正）
- ボラティリティ系 ±10（強さ・安定性）
- 出来高系 ±10（信頼性）
- サイクル系 ±10（転換点の補正）

`scoreGroup` の割り当て:

- trend: `sma25`, `sma75`, `sma200`, `ema50`, `macd`, `ichimoku`, `psar`
- momentum: `momentum`, `roc`（MACD はトレンドへ）
- oscillator: `rsi`, `cci`, `stoch`, `willr`, `psy`（RSI / CCI はオシレーターへ）
- volatility: `bb`, `atr`, `stdev`, `keltner`
- volume: `volume`, `obv`, `vwap`, `mfi`, `volumeProfile`
- cycle: `fibonacci`（一目はトレンドへ）
- 採点しない: `elliott`

### 合成

- 各指標はウォームアップ中 `null`
- グループ平均は有効点だけ。有効点が 0 件ならそのグループ寄与は 0（配点の再正規化はしない）
- `groupContrib = (groupAvg / 100) * groupWeight`
- `total = clamp(sum(groupContrib), -100, 100)`

### 指標ごとの採点（-100〜+100）

方向性の連続量は `100 * tanh(x)` でクランプする。

- **MA / EMA / VWAP**: `x = (close - ma) / ma / 0.05`（約 5% 乖離で |score|≈76）。`ma == 0` は `null`
- **MACD**: ヒストグラムを終値の 1% で正規化した tanh を 70%、ラインとシグナルの符号（上なら +100、下なら -100）を 30% で合成
- **一目**: 終値と雲（上 +100 / 中 0 / 下 -100）、転換と基準、終値と 26 本前終値の 3 要素を平均
- **PSAR**: 終値が点より上なら +100、下なら -100、同値は 0
- **Momentum**: `x = mom / (close * 0.05)`
- **ROC**: `x = roc / 5`（ROC は %）
- **オシレーター（平均回帰の補正）**: 中立 0、過熱はマイナス、売られすぎはプラス
  - RSI / Stoch %K / PSY: 20→+100、30→+50、50→0、70→-50、80→-100（区分線形。範囲外は端点）
  - Williams %R: `willr + 100` して RSI と同じスケール
  - CCI: -200→+100、-100→+50、0→0、+100→-50、+200→-100
- **BB / ケルトナー**: %B を `(pctB - 0.5) * 200`。バンド幅 0 は 0
- **ATR / 標準偏差**: その SMA に対する相対的な大きさ `tanh(value / sma - 1)` に、終値と SMA25 の符号を掛ける
- **生出来高**: 陰陽（終値≥始値なら +）× `100 * tanh(volume / sma20(volume) - 0.5)`
- **OBV**: OBV とその SMA20 を MA と同じ 5% スケール（分母は `|sma|`、0 のときは 1）
- **MFI**: `x = (mfi - 50) / 20`（出来高グループは方向の信頼性）
- **Volume Profile**: 最大出来高ビンの中央（POC）を MA と同じ 5% スケール
- **フィボナッチ**: 表示期間の高値〜安値における終値位置。安値 +100、中央 0、高値 -100。幅 0 は 0

### 状態ラベル

総合スコアの区分中点:

- ≥77.5 非常に強い上昇
- ≥37.5 上昇トレンド
- ≥7.5 レンジだがやや上向き
- ≥-10 完全なレンジ
- ≥-42.5 レンジだがやや下向き
- ≥-80 下降トレンド
- それ以外 暴落に近い強い下降

### チャート背景

- 日足ごとの総合スコアを価格ペイン全高の縦帯にする
- 色は総合スコア表のストップ（+95 / +60 / +15 / 0 / -20 / -65 / -95）を線形補間。0 は透明
- ズーム/パンに追従するため lightweight-charts v5 の series primitive で描く
- 直近バーの総合スコアと状態ラベルをチャート上段に出す

## 理由

- 分類 UI の学習用重複と、数値合成の一意性を分けないと配点が崩れる
- 計算を Python に置くことで指標計算と採点を同じ OHLC 上で固定テストできる
- トグル非依存にすることで「相場の状態」と「今見ている線」を混同しない
- オシレーターを平均回帰の補正にすると、トレンド系の方向性を過熱で弱められる

## 結果・制約

- 指標パラメータの自由編集は対象外（ADR 006 の延長）
- 分足・月足・リアルタイム、スコアの永続化は対象外
- エリオットの自動カウントは対象外
